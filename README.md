# Social Development Events Platform

A modern, responsive web application built with Next.js (App Router), TypeScript, Tailwind CSS, DaisyUI, and MongoDB for organizing and managing social development events, community service, and charity drives.

## 🚀 Tech Stack

- **Framework:** Next.js (App Router)
- **Language:** TypeScript
- **Styling:** Tailwind CSS, DaisyUI
- **Database:** MongoDB
- **Icons:** React Icons
- **Authentication:** Better-Auth (with Google OAuth integration)

## ✨ Features

- **Responsive Dark-Blue Theme:** Cohesive, modern glassmorphism UI across all pages.
- **Event Management:** Create, view, and explore social events with specific categories (Community Service, Blood Donation, Environmental Drive, etc.).
- **User Authentication:** Secure Login and Registration pages integrated with Google OAuth.
- **Dynamic Navbar & Footer:** Consistent navigation and professional footer layout.
